# Cancha Central

Prototipo funcional para la Entrega 2. Desarrollado con HTML, CSS y JavaScript.

Repositorio: https://github.com/SantiRCruz/cancha-central

## Ejecutar localmente

Desde esta carpeta, ejecute `python3 -m http.server 8000` y abra `http://localhost:8000`.

## Funcionalidades

- Noticias renderizadas dinámicamente desde `data/noticias.json`.
- Búsqueda y filtros por categoría.
- Vista de detalle de noticia.
- Favoritos guardados con `localStorage`.
- Formulario con validaciones y confirmación visual.
- Mini CRUD local para crear y eliminar noticias.

## Imágenes

Las fotografías de las noticias se almacenan de forma local en `assets/`. Se obtuvieron de Unsplash y Pexels para la maqueta académica.
